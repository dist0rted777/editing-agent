# Clean SaaS Motion Direction Skill

## Core Principles
1. **Never restate the full voiceover on screen.** Extract 2 to 4 punchy anchor words per beat.
2. **Cut dead air aggressively.** Keep visual rhythm changing every 2.5 to 4.0 seconds.
3. **Zero generic AI slop.** Avoid neon glow filters, rainbow gradients, and heavy CSS blur passes (also keeps local rendering fast).
4. **Brand lock.** Use only `brand.colors` and `brand.typography` tokens.

## Beat Structure
- **0.0s - 3.0s (Hook):** Pair the opening value proposition with a `kinetic-text` or `hook` component.
- **Middle Beats:** Alternate raw product footage with `feature-callout` overlays synced to exact transcript timestamps.
- **Final 2.5s (Outro):** Clean brand lockup using `outro` component.
